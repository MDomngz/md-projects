Section 1

GitHub Account & Repositories

GitHub is where your code and design system components live. Even as a UX designer, having a GitHub account enables collaboration with developers and access to AI tools like Copilot.

1
Create a GitHub Account
Sign up and configure your profile
▼
  1. Go to github.com/signup
  2. Enter your email address (use your work email if setting up for your team)
  3. Create a password and choose a username
  4. Verify your account via the email confirmation
  5. On the welcome screen, select your interests — "Design" and "Web development" are good picks
⚡
Tip: Enable Two-Factor Authentication Go to Settings → Password and authentication → Enable 2FA. This is required for many organizations and is a security best practice.
2
Understand Repos, Branches, and Commits
Core concepts you'll use daily
▼
Concept What It Means Design Analogy
Repository (Repo) A project folder that tracks all changes Like a Figma file with full version history
Branch A parallel copy for making changes safely Like duplicating a Figma page to try new layouts
Commit A saved snapshot of your changes with a message Like naming a version in Figma's history
Pull Request (PR) A request to merge your branch into the main code Like presenting your design for team review
3
Create Your First Repository
Set up a project to work with
▼
  1. Click the + icon in the top-right of GitHub, then New repository
  2. Name it something descriptive, like my-design-system or ux-prototypes
  3. Add a description (e.g., "Component prototypes and design tokens")
  4. Choose Public or Private visibility
  5. Check Add a README file
  6. Click Create repository
ℹ
If you're joining an existing team, your organization admin will likely invite you to existing repos. You can skip this step and clone the team's repos instead.
4
Clone a Repo to Your Computer
Download a repo so you can work on it locally
▼

Cloning copies the repo to your local machine. You'll do this from VS Code (which we'll set up next) or the terminal.

# Using the terminal git clone https://github.com/YOUR-USERNAME/my-design-system.git # Navigate into the folder cd my-design-system

Or in VS Code: press Cmd+Shift+P (Mac) / Ctrl+Shift+P (Windows), type Git: Clone, and paste the repo URL.

Section 2

VS Code Setup

Visual Studio Code is a free, lightweight code editor that integrates with GitHub, Copilot, and MCP servers. It's the hub of your AI-powered workflow.

1
Download & Install VS Code
Get the editor on your machine
▼
  1. Go to code.visualstudio.com
  2. Download the installer for your operating system (Mac, Windows, or Linux)
  3. Run the installer and follow the prompts
  4. Launch VS Code when installation is complete
⚡
Mac Users: After installing, open VS Code, press Cmd+Shift+P, and type Shell Command: Install 'code' command in PATH. This lets you open VS Code from the terminal by typing code . in any folder.
2
Sign In with GitHub
Link your GitHub account to VS Code
▼
  1. In VS Code, click the Accounts icon (person silhouette) in the bottom-left of the sidebar
  2. Click Sign in with GitHub
  3. A browser window will open — authorize the connection
  4. You'll be redirected back to VS Code, now connected

This connection enables syncing your settings, accessing private repos, and using GitHub Copilot.

3

Extensions that make VS Code designer-friendly
▼

Open the Extensions panel with Cmd+Shift+X (Mac) / Ctrl+Shift+X (Windows) and search for these:

Extension What It Does Category

Live Server Preview HTML files in a browser with auto-reload Preview
Prettier Auto-format your code to look clean Formatting

4
Open a Repo in VS Code
Start working on your project
▼

There are three easy ways to open a project:

  1. File → Open Folder: Navigate to your cloned repo folder and open it
  2. Terminal: Navigate to your project folder and type code .
  3. Command Palette: Press Cmd+Shift+P, type Git: Clone, and paste a repo URL

Once open, you'll see the file tree on the left, editor in the center, and terminal at the bottom (toggle with Ctrl+`).

Connect GitHub Copilot to VS Code

GitHub Copilot is an AI pair programmer that suggests code as you type. It can help UX designers write HTML prototypes, CSS components, and even React code faster.

1
Get a Copilot Subscription
Choose the right plan for you
▼
Plan Price Best For
Copilot Free $0/month Trying it out — limited completions per month
Copilot Pro $10/month Individual designers and freelancers
Copilot Business $19/user/month Teams — your org may already provide this
ℹ
Check with your team lead — many organizations provide Copilot Business licenses to all team members. You may already have access.
  1. Go to github.com/features/copilot
  2. Click Get Copilot and choose your plan
  3. Complete the signup process
2
Install Copilot Extensions in VS Code
Add Copilot and Copilot Chat
▼
  1. Open VS Code
  2. Go to Extensions (Cmd+Shift+X / Ctrl+Shift+X)
  3. Search for "GitHub Copilot" and click Install
  4. Search for "GitHub Copilot Chat" and click Install
  5. VS Code will prompt you to sign in with GitHub — authorize the connection

After installation, you'll see a Copilot icon in the bottom-right status bar. A filled icon means it's active and ready.

3
Using Copilot for Design Work
Practical ways designers can leverage Copilot
▼

Inline Suggestions: Start typing and Copilot will suggest completions in gray text. Press Tab to accept, or Esc to dismiss.

/* Type a comment describing what you want: */ /* Create a card component with rounded corners, shadow, and hover effect */ /* Copilot will suggest the full CSS below your comment */ .card { border-radius: 12px; box-shadow: 0 2px 8px rgba(0,0,0,0.1); transition: transform 0.2s ease; padding: 24px; } .card:hover { transform: translateY(-2px); }

Copilot Chat: Press Cmd+Shift+I to open the chat panel. Ask questions like:

  • "Convert this CSS to match the VA Design System spacing tokens"
  • "Create an accessible button component in HTML"
  • "Explain what this React component does"
  • "Help me write a responsive grid layout"
⚡
Designer Tip: Use comments as prompts. Write a plain-English description of the component you want, and Copilot will generate the code. This works especially well for HTML/CSS prototypes.
4
Copilot Agent Mode
Let Copilot handle multi-step tasks
▼

Copilot's Agent Mode (available in Copilot Chat) can handle complex, multi-step tasks — like scaffolding a full component, editing multiple files, or running terminal commands.

  1. Open Copilot Chat (Cmd+Shift+I)
  2. Look for the model selector dropdown at the top of the chat — you can pick models like GPT-4o or Claude
  3. In the chat input, toggle to Agent mode (look for the mode selector)
  4. Describe what you need: "Create a responsive navigation component using the VADS header pattern"
  5. Copilot will plan the steps, create files, and ask for your approval before making changes
★
Agent vs. Chat vs. Edit: Use Chat for questions and explanations. Use Edit (Cmd+Shift+I and select Edit mode) for targeted code changes. Use Agent for multi-file tasks where you want Copilot to drive.
Section 4

Understanding MCP

The Model Context Protocol (MCP) is an open standard that lets AI tools connect to external services — your design files, databases, APIs, and more. Think of it as giving your AI assistant eyes and hands beyond just code.

1
What Is MCP?
The bridge between AI and your tools
▼

MCP (Model Context Protocol) is a standard created by Anthropic that defines how AI assistants communicate with external tools and data sources. Without MCP, an AI can only see the text you type. With MCP, it can:

  • Read your Figma designs and understand component structure
  • Access your file system to read and write code
  • Query APIs and databases for real data
  • Run commands in your terminal
  • Search the web for documentation and references
Term Meaning
MCP Server A small program that connects a specific tool (Figma, GitHub, Slack, etc.) to AI
MCP Client The AI application (VS Code Copilot, Claude Code, Cursor, etc.) that talks to MCP servers
Tools Actions the MCP server exposes — like "get design," "create file," "search"
Resources Data the MCP server can provide — like file contents, design metadata, etc.
2
How MCP Works in VS Code
Configure MCP servers for Copilot
▼

VS Code supports MCP servers through its settings. When you configure an MCP server, GitHub Copilot (in Agent mode) can use its tools.

Where to configure:

  • User-level: In your VS Code settings (settings.json) — available in all projects
  • Project-level: In a .vscode/mcp.json file — shared with your team via the repo

The configuration format looks like this:

// .vscode/mcp.json { "servers": { "my-server-name": { "type": "stdio", "command": "npx", "args": ["-y", "@example/mcp-server"], "env": { "API_KEY": "${input:apiKey}" } } }, "inputs": [ { "id": "apiKey", "description": "API key for the service", "type": "promptString", "password": true } ] }
ℹ
The ${input:apiKey} syntax prompts you for the value when the server starts, so you never have to hard-code secrets in your config files.
3

Section 5

Setting Up Figma MCP

The Figma MCP server lets AI tools read your designs, extract styles, understand component structure, and even write designs back into Figma. It's the bridge between your design files and code.

1
Get a Figma Access Token
Create a personal access token in Figma
▼
  1. Open Figma and click your profile icon in the top-left
  2. Go to Settings
  3. Scroll down to Personal access tokens
  4. Click Generate new token
  5. Give it a descriptive name like "MCP Server Access"
  6. Set the expiration (90 days is a good balance of security and convenience)
  7. For scopes, enable at minimum:
    • File content — Read access (required)
    • File content — Write access (needed for code-to-design)
    • Dev resources — Read and Write (for Code Connect)
  8. Click Generate token and copy it immediately — you won't be able to see it again
⚠
Keep your token secret. Never commit it to a repo, paste it in Slack, or share it in a document. Store it in a password manager or use environment variables.
2
Configure Figma MCP in VS Code
Add the Figma MCP server to your project
▼

Create a .vscode/mcp.json file in your project root:

// .vscode/mcp.json { "servers": { "figma": { "type": "stdio", "command": "npx", "args": ["-y", "figma-developer-mcp", "--stdio"], "env": { "FIGMA_API_KEY": "${input:figmaApiKey}" } } }, "inputs": [ { "id": "figmaApiKey", "description": "Your Figma Personal Access Token", "type": "promptString", "password": true } ] }

When you start a Copilot Agent session, VS Code will prompt you for the Figma token. It's stored securely in your session and never written to disk.

⚡
Alternative: Environment variable. If you prefer not to be prompted each time, set FIGMA_API_KEY in your shell profile (~/.zshrc or ~/.bashrc) and replace the env value with just "FIGMA_API_KEY": "${env:FIGMA_API_KEY}".
3
What Figma MCP Can Do
Capabilities and practical workflows
▼

Once connected, the Figma MCP server gives your AI assistant these abilities:

Capability How to Use It
Read designs Paste a Figma URL and ask "Implement this design" — the AI reads the layout, colors, typography, and spacing

4
Using Figma MCP with Copilot
Step-by-step design-to-code workflow
▼

Here's how to go from a Figma design to code using Copilot + Figma MCP:

  1. Open your project in VS Code
  2. Open Copilot Chat (Cmd+Shift+I) and switch to Agent mode
  3. Copy the URL of a Figma frame or component (right-click → Copy link in Figma)
  4. In the chat, type something like:
Look at this Figma design: [paste your Figma URL here] Create an accessible HTML/CSS component that matches this design. Use semantic HTML, ARIA attributes where needed, and follow WCAG 2.1 AA standards.
  1. Copilot will use the Figma MCP to read the design, then generate matching code
  2. Review the generated code — check spacing, colors, and accessibility
  3. Click Accept to apply the changes to your files
★
Pro tip: Be specific in your prompts. Instead of "make this design," say "Create a React component using USWDS classes that matches this card design. Include responsive breakpoints at 768px and 1024px."
5
Using Figma MCP with Claude Code
Alternative setup for the Claude Code CLI
▼

If you use Claude Code (Anthropic's CLI tool), you can also connect Figma MCP there. Claude Code supports MCP servers natively.

Add the Figma MCP server to your project's .claude/settings.json:

// .claude/settings.json { "mcpServers": { "figma": { "command": "npx", "args": ["-y", "figma-developer-mcp", "--stdio"], "env": { "FIGMA_API_KEY": "your-token-here" } } } }

Or set the token as an environment variable first:

# Add to ~/.zshrc or ~/.bashrc export FIGMA_API_KEY="your-token-here" # Then in .claude/settings.json, reference it: # "FIGMA_API_KEY": "${FIGMA_API_KEY}"

Once configured, you can use Claude Code with commands like:

  • "Look at this Figma design and create a matching component"
  • "Generate a design library in Figma based on our codebase"
  • "Set up Code Connect for our component library"
